# 接口 404

接口 404 通常有三层来源：前端代理、网关路由、后端 Controller。

## 检查顺序

1. 前端请求路径是否以 `/admin/api`、`/erp/api`、`/amazon/api` 等前缀开始。
2. Vite proxy 是否覆盖该路径。
3. Nacos `wimoor-gateway` 是否配置对应 Path。
4. 目标服务是否注册到 Nacos。
5. Controller 的 `@RequestMapping` 和方法映射是否匹配。

rg -n "目标路径片段" -g "*.java"
