# 关于本文档

本文档采用 Obsidian 本地维护、Docsify 在线渲染、GitHub Pages 托管的结构：

- `docs/zh-cn` 是 Obsidian vault 根目录。
- `README.md` 为首页。
- `_sidebar.md` 为 Docsify 侧边栏。
- `_navbar.md` 为 Docsify 顶部导航。
- `_content/` 按介绍、功能、原理、流程、技巧、问答和参考索引分层。
- `docs/index.html` 是 GitHub Pages `/docs` 发布源的站点入口。

文档事实来源：

- 仓库根目录 `README.md` 和 `AGENTS.md`。
- Maven `pom.xml` 模块结构。
- `wimoorui/package.json` 与 `wimoorui/vite.config.js`。
- 后端启动类、Controller、Feign、配置文件。
- `init-config/mysql`、`init-config/nacos`、`init-config/seata`。
- [项目地图](../../project-map/README.md)。
- [Obsidian 维护规范](skill/obsidian-workflow.md)。
- [GitHub Pages 发布流程](skill/github-pages.md)。
